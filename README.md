# 邱关源《电路》智能出题与 ASCII→SVG 配图 Agent (`setting-a-question`)

本项目针对理工科专业课（以经典教材**邱关源《电路》**为例）的智能出题与自动配图场景，提供了一套**四步闭环出题 + 专职 ASCII→SVG 配图 Agent 架构**，并与传统的**单轮 Prompt 直接生成（Naive Baseline）**进行了实测对比。

---

## 一、为什么单轮 Prompt 出不出好题？（三大结构性病根）

在实际工程中，如果把考纲范围、难度梯度、陷阱要求与配图需求揉成一段单轮 Prompt 直接发给大模型：

> `stu_001, 出 3道题；难度比例：1：1：1；习题范围：普通的电阻电路分析、电路定理、二端口、正弦稳态电路、三相电路、耦合电路、谐振、周期非正弦、暂态（一阶电路、二阶电路）、滤波器、均匀传输线、图论；参考教材：邱关源《电路》；题目要求：简单题需≥2步计算、中等题含多考点+隐性陷阱、难题跨模块+概念误导+定理前提甄别，每个题目要带图；例如出电路定理支路上完全可以加受控源，而不是简单图`

单轮生成会稳定暴露出三个典型毛病（详见实测产物 [`examples/naive_single_prompt_output.md`](examples/naive_single_prompt_output.md)）：

1. **章节向低维纯电阻坍缩**：13 个章节写在一起时，大模型顺着概率最大、最省算力的路径走，第 1 题永远挑第 1 章「电阻电路分析」（$12\text{ V}$ 直流源 + 纯电阻串并联），不仅回避受控源，还会因为随手编造参数导致解出 $\frac{480}{71}\text{ V}$、$\frac{160}{71}\text{ A}$ 这类教材里绝不会出现的怪异分数。
2. **单轮同时出题+画图导致认知与 Token 挤兑**：在同一个单轮回复里既要构思 3 道题、凑数算解析，又要手写 3 张电路图，大模型的注意力和输出窗口被严重稀释——要么为了好画图而把拓扑退化成最简单的纯电阻框线，要么因图形代码冗长在半途耗尽 Token 截断。
3. **用定性文字问答糊弄“概念误导/定理甄别”**：当要求“难题含概念误导+定理前提甄别”时，单轮大模型往往在最后一问塞一句定性文字问答（如“某同学认为功率可以直接用叠加定理相加，对不对？”或“仅根据给定参数能否判断……说明理由”），缺乏硬核的定量数值计算耦合。

## 二、解耦破局：为什么 DeepSeek 单独画 SVG 就能画好？

实验发现：**DeepSeek 本身完全具备绘制任意复杂拓扑 SVG 电路图的能力！** 只要不在单轮里让它“既当命题人、又当解题人、还要一次画三张图”，而是将**「拓扑构思（ASCII 草图）」**与**「专职图形渲染（ASCII → SVG）」**解耦：

1. **出题阶段只画轻量级 ASCII 电路拓扑草图**：几行字符即可清晰标明节点、支路、受控源极性与控制量方向，几乎不占 Token；
2. **画图阶段每次只盯 1 道题（`ascii_to_svg.py`）**：单独调用一次 DeepSeek，输入**单道题的题干拓扑描述 + ASCII 拓扑草图** + 国标图元规范（圆圈独立源、红色菱形 `<polygon>` 受控源、长方形 `<rect>` 电阻、平行板电容、带斜杆动作箭头的换路开关、二端口虚线框），配合 XML/几何防穿模自检（自动检测导线是否贯穿元件内部、文字是否越界或重叠），DeepSeek 就能一次性生成教科书级的任意拓扑 SVG 电路图！

### 四步闭环流水线架构

```text
[原始需求] 
    │
    ▼
Step 1: Planner + SymPy Solver + ASCII Topology Sketch (circuit_templates.py)
    │  ① 跨章节正交抽样 1:1:1（第4章含受控源电路定理 / 第7章一阶RC换路暂态 / 第16章非互易二端口+定理甄别）
    │  ② SymPy 符号精确求解节点/端口方程，确保所有中间量、正确解与典型错解对比值均为漂亮整数
    │  ③ 生成轻量级 ASCII 电路拓扑草图，理清节点与支路连接关系
    ▼
Step 2: Dedicated DeepSeek ASCII-to-SVG Artist (ascii_to_svg.py)
    │  ① 1 题 1 调用：输入【单题题干描述 + ASCII 电路拓扑图】-> DeepSeek 自主生成完整 <svg>...</svg>
    │  ② 自动化几何防穿模自检（拦截导线穿过元件短路、<tspan> 重叠、生僻下标乱码）+ CairoSVG 渲染高清 PNG
    ▼
Step 3: Controlled Question & Solution Writer (agent.py + DeepSeek API)
    │  严格锚定 SymPy Ground-Truth 撰写教材级题干（同时展示 ASCII 草图与 SVG/PNG 配图）、定量陷阱设问与分步解析
    ▼
Step 4: Red-Team Critic Loop (critic.py)
       硬规则（模块覆盖、高阶图元、反低幼问答正则、SymPy数值对齐）+ LLM 教研室主任深度评审，不达标自动打回重写
```

## 三、项目结构与快速运行

```text
.
├── agent.py                 # 四步闭环出题与配图 Agent 主程序
├── ascii_to_svg.py          # DeepSeek 专职电路图画师（单题 ASCII 拓扑草图 -> SVG 源码 + 几何防穿模自检 + PNG 渲染）
├── circuit_templates.py     # 参数化电路拓扑 + ASCII 草图定义 + SymPy 符号求解器
├── critic.py                # 教研主任红队自动审题器（硬规则 + LLM 评审）及 DeepSeek API 客户端
├── naive_baseline.py        # 单轮 Prompt 对照组实验脚本
├── README.md                # 项目说明文档
└── examples/                # 实跑输出产物目录
    ├── stu_001_exam.md              # 最终生成的 3 道真题与标准解析（含 ASCII 草图与 SVG/PNG 配图对照）
    ├── q1.svg / q1.png              # DeepSeek 由题1 ASCII 草图自主生成的 SVG/PNG（含 CCCS 戴维南等效）
    ├── q2.svg / q2.png              # DeepSeek 由题2 ASCII 草图自主生成的 SVG/PNG（含开关与 VCVS 一阶 RC 暂态）
    ├── q3.svg / q3.png              # DeepSeek 由题3 ASCII 草图自主生成的 SVG/PNG（含受控源非互易二端口网络）
    ├── run_log.json                 # 完整运行日志（含 SymPy 验算值、ASCII->SVG 转换日志、Critic 评分与 Token 统计）
    └── naive_single_prompt_output.md # 单轮 Prompt 对照组原始输出与违规拦截记录
```

### 运行指令

1. 配置环境变量（在项目根目录创建 `.env`，已被 `.gitignore` 忽略）：
   ```ini
   DEEPSEEK_API_KEY=your_api_key_here
   DEEPSEEK_BASE_URL=https://api.deepseek.com
   DEEPSEEK_MODEL=deepseek-chat
   ```
2. 运行单轮 Prompt 对照组实验：
   ```bash
   python3 naive_baseline.py
   ```
3. 运行四步闭环出题与 `ASCII -> SVG` 配图 Agent：
   ```bash
   python3 agent.py
   ```

## 四、`stu_001` 实测三道真题：从 ASCII 拓扑草图到 DeepSeek 自主绘制 SVG

### 题 1（简单 ★）：第 4 章 电路定理 —— 含受控电流源（CCCS）的戴维南等效与最大功率传输
- **考点与定量陷阱**：引入菱形受控电流源 $1\cdot I_1$，考察开路电压 $U_{\text{oc}}=48\text{ V}$、短路电流 $I_{\text{sc}}=4\text{ A}$、等效内阻 $R_{\text{eq}}=12\ \Omega$（若误将受控源置零开路会算得错误值 $8\ \Omega$）及最大功率 $P_{\max}=48\text{ W}$。
- **输入给 `ascii_to_svg.py` 的 ASCII 拓扑草图**：
  ```text
             R1 = 6 Ω         节点 A        R3 = 4 Ω                   a
      +------[ 6 Ω ]------------●-----------[ 4 Ω ]-----------●--------o - - - - +
      |                         |                             |                  |
      |                         | I1 (↓)                      |                  |
     (+)                        v                            / \                 |
    ( Us ) 36 V              [ R2 ] 12 Ω                    < ↑ > 1·I1 (CCCS)  [ RL ] (可变负载)
     (−)                        |                            \ /                 |
      |                         |                             |                  |
      +-------------------------●-----------------------------●--------o - - - - +
                                |                                      b
                               === (GND)
  ```

### 题 2（中等 ★★）：第 7 章 一阶电路的时域分析 —— 含开关换路与受控电压源（VCVS）的 RC 暂态响应
- **考点与双重隐性陷阱**：
  1. **开路支路中的受控电压源不等于零**：$t=0_-$ 稳态电容开路，$R_3$ 无电流，但串联的受控电压源 $2i_x(0_-)=6\text{ V}$ 仍在，故 $u_C(0_+)=18+6=24\text{ V}$（漏算受控源会误得 $18\text{ V}$）；
  2. **受控源调制时间常数**：$t\ge 0$ 开关断开后，从电容端口看进去的等效内阻 $R_{\text{eq}}=R_2+R_3+2=12\ \Omega$（误将受控源短路会得 $10\ \Omega$），$\tau=R_{\text{eq}}C=3\text{ s}$，$u_C(t)=24e^{-t/3}\text{ V},\ i_C(t)=-2e^{-t/3}\text{ A}$。
- **输入给 `ascii_to_svg.py` 的 ASCII 拓扑草图**：
  ```text
             R1 = 4 Ω     S (t=0 断开)   节点 A      R3 = 4 Ω        2ix (VCVS)     节点 B
      +------[ 4 Ω ]------o  /  o---------●---------[ 4 Ω ]--------< −   + >---------●-------+
      |                                   |                                                  |
      |                                   | ix (↓)                                           | iC(t) (↓)
     (+)                                  v                                               +  v
    ( Us ) 30 V                         [ R2 ] 6 Ω                                   uC(t) ===== C = 0.25 F
     (−)                                  |                                               -  |
      |                                   |                                                  |
      +-----------------------------------●--------------------------------------------------+
                                          |
                                         === (GND)
  ```

### 题 3（困难 ★★★）：第 16 章 二端口网络 + 第 4 章 电路定理前提甄别
- **考点与定理前提定量甄别**：
  1. **互易定理失效定量甄别**：求得 $\mathbf{Z}=\begin{bmatrix}6 & 4\\8 & 6\end{bmatrix}\ \Omega$，由 $Z_{12}=4\ \Omega \neq Z_{21}=8\ \Omega$ 证明受控源 $4I_1$ 破坏互易性（若误令 $Z_{21}=Z_{12}=4\ \Omega$，负载电压会算错为 $28.8\text{ V}$）；
  2. **叠加定理与功率耦合项定量计算**：双源共同作用时 $I_L=6\text{ A},\ U_L=36\text{ V},\ P_L=216\text{ W}$；单独作用时 $I_L'=4\text{ A}\ (P_L'=96\text{ W})$，$I_L''=2\text{ A}\ (P_L''=24\text{ W})$；电流满足 $4+2=6\text{ A}$，而功率差值 $\Delta P = 216-(96+24)=96\text{ W}$，恰等于交叉耦合功率项 $2I_L'I_L''R_L=96\text{ W}$。
- **输入给 `ascii_to_svg.py` 的 ASCII 拓扑草图**：
  ```text
                          + - - - - [ 含受控源线性二端口网络 N ] - - - - +
           Rs = 2 Ω   I1  |    R1 = 2 Ω       节点 M   R3 = 2 Ω   4I1    |   I2
      +----[ 2 Ω ]--->--o 1 ---[ 2 Ω ]---------●------[ 2 Ω ]---< − + >--o 2 --<--+----------+
      |                   |                    |                         |        |          |
     (+)                  |                    |                         |       (↑)         | IL (↓)
    (Us1) 32 V            |                 [ R2 ] 4 Ω                   |      (Is2) 8 A  [ RL ] 6 Ω
     (−)                  |                    |                         |       ( )         |
      |                   |                    |                         |        |          |
      +-----------------o 1'-------------------●-------------------------o 2'-----+----------+
                          + - - - - - - - - - - - - - - - - - - - - - - -+
  ```
