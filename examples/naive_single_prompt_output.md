## 题目一（简单题，≥2 步计算）

**范围：** 普通电阻电路分析 + 电路定理  
**难度：** 简单

### 题目

如图所示直流电阻电路，已知 \(R_1=2\Omega,\ R_2=4\Omega,\ R_3=4\Omega,\ R_4=6\Omega,\ R_5=3\Omega\)，电压源 \(U_S=12V\)，电流源 \(I_S=2A\)。  
求电流 \(I\)（流过 \(R_5\) 的电流，方向向下）。

```text
        +---- R1 ----+---- R3 ----+
        |            |            |
       (↑)          R2           R4
       Us=12V        |            |
        |            |            |
        +---- Is ----+---- R5 ----+
            2A↑           I↓
```

> 图中：左侧支路为 \(U_S\) 与 \(R_1\) 串联；中间竖直支路为 \(R_2\)；右侧竖直支路为 \(R_3\) 与 \(R_4\) 串联；底部中间有电流源 \(I_S\) 与 \(R_5\) 并联支路。  
> 为明确节点关系，可等效看作：上节点 A，下节点 B；\(R_1\) 接在 A 与左节点之间，\(U_S\) 接左节点与 B；\(R_2\) 接 A 与 B；\(R_3+R_4\) 接 A 与 B；\(I_S\) 与 \(R_5\) 接 A 与 B。  
> 即：A、B 之间共有四条并联支路：  
> 1）\(R_1+U_S\) 支路；2）\(R_2\) 支路；3）\(R_3+R_4\) 支路；4）\(I_S\) 与 \(R_5\) 并联支路。

### 解析

将电路看成节点 A、B 之间的并联结构。设 \(U_{AB}=U\)。

1. 对 \(R_1+U_S\) 支路，取 B 为参考点，则 A 点经 \(R_1\) 到电压源正端，电压源负端接 B。  
   该支路从 A 流向 B 的电流为  
   \[
   I_1=\frac{U-U_S}{R_1}=\frac{U-12}{2}
   \]

2. \(R_2\) 支路电流  
   \[
   I_2=\frac{U}{R_2}=\frac{U}{4}
   \]

3. \(R_3+R_4\) 支路电流  
   \[
   I_3=\frac{U}{R_3+R_4}=\frac{U}{10}
   \]

4. 电流源与 \(R_5\) 并联支路：电流源方向为从 B 指向 A（图中标“2A↑”），即注入 A 节点 2A；\(R_5\) 中电流从 A 到 B 为  
   \[
   I_5=\frac{U}{R_5}=\frac{U}{3}
   \]  
   该支路对 A 节点的净流出电流为  
   \[
   I_4=I_5-I_S=\frac{U}{3}-2
   \]

5. 对节点 A 列 KCL：  
   \[
   I_1+I_2+I_3+I_4=0
   \]  
   即  
   \[
   \frac{U-12}{2}+\frac{U}{4}+\frac{U}{10}+\frac{U}{3}-2=0
   \]

6. 求公分母 60：  
   \[
   30(U-12)+15U+6U+20U-120=0
   \]  
   \[
   30U-360+15U+6U+20U-120=0
   \]  
   \[
   71U=480
   \]  
   \[
   U=\frac{480}{71}\text{ V}
   \]

7. 流过 \(R_5\) 的电流方向向下（A→B）：  
   \[
   I=\frac{U}{R_5}=\frac{480/71}{3}=\frac{160}{71}\text{ A}\approx 2.2535\text{ A}
   \]

**答案：**  
\[
\boxed{I=\frac{160}{71}\text{ A}\approx 2.25\text{ A，方向向下}}
\]

## 题目二（中等题，含多考点 + 隐性陷阱）

**范围：** 正弦稳态电路 + 耦合电路 + 谐振  
**难度：** 中等

### 题目

如图所示正弦稳态电路，角频率 \(\omega=1000\ \text{rad/s}\)。  
已知：
\[
R_1=10\Omega,\quad L_1=10\text{ mH},\quad L_2=20\text{ mH},\quad M=5\text{ mH},
\]
\[
C=50\mu F,\quad R_2=20\Omega
\]
电压源 \(u_S(t)=20\sqrt2\cos(1000t)\text{ V}\)。  
求：

1. 耦合线圈的互感抗 \(X_M\) 与两线圈自感抗 \(X_{L1},X_{L2}\)；
2. 从电源看进去的输入阻抗 \(Z_{in}\)；
3. 电容 \(C\) 两端电压有效值 \(U_C\)；
4. 判断电路是否发生谐振，并说明理由。

```text
        +---- R1 ----+---- L1(同名端•)----+
        |            |                   |
       (↑)           C                  (M)
       us(t)         |                   |
        |            |                   |
        +------------+---- L2(同名端•)----+
                         |
                         R2
                         |
                        GND
```

> 说明：\(L_1\) 与 \(L_2\) 串联在同一回路中，二者同名端均在上端；\(C\) 并联在 \(R_1\) 与 \(L_1\) 的连接点与地之间；\(R_2\) 与 \(L_2\) 串联后接地。  
> 为便于计算，可将电路看作：电源经 \(R_1\) 后到节点 A；A 点对地接电容 \(C\)；A 点经 \(L_1\) 到节点 B；B 点经 \(L_2\) 与 \(R_2\) 串联到地。\(L_1,L_2\) 存在互感 \(M\)，同名端均在 A、B 侧上端。

### 解析

#### 1. 感抗与互感抗

\[
X_{L1}=\omega L_1=1000\times 10\times10^{-3}=10\Omega
\]
\[
X_{L2}=\omega L_2=1000\times 20\times10^{-3}=20\Omega
\]
\[
X_M=\omega M=1000\times 5\times10^{-3}=5\Omega
\]

#### 2. 输入阻抗

采用相量法，设 \(\dot U_S=20\angle0^\circ\text{ V}\)。

由于 \(L_1,L_2\) 串联且同名端均在上端，电流从 A 经 \(L_1\) 到 B，再经 \(L_2\) 到地，两线圈电流均从同名端流入，因此互感电压与自感电压同极性，串联等效电感为  
\[
L_{eq}=L_1+L_2+2M
\]
所以串联等效感抗为  
\[
X_{eq}=X_{L1}+X_{L2}+2X_M=10+20+2\times5=40\Omega
\]
即串联部分阻抗为  
\[
Z_{L}=j40\Omega
\]
再串联 \(R_2=20\Omega\)，得 B 到地支路阻抗  
\[
Z_2=R_2+j40=20+j40\Omega
\]

电容容抗：
\[
X_C=\frac{1}{\omega C}=\frac{1}{1000\times50\times10^{-6}}=20\Omega
\]
所以电容支路阻抗  
\[
Z_C=-j20\Omega
\]

从节点 A 到地看，支路为 \(C\) 与 \((L_1+L_2+2M+R_2)\) 并联：
\[
Z_A=Z_C\parallel Z_2=\frac{(-j20)(20+j40)}{20+j40-j20}
=\frac{(-j20)(20+j40)}{20+j20}
\]
先算分子：
\[
(-j20)(20+j40)=800-j400
\]
分母：
\[
20+j20
\]
因此
\[
Z_A=\frac{800-j400}{20+j20}
\]
有理化：
\[
Z_A=\frac{(800-j400)(20-j20)}{20^2+20^2}
=\frac{8000-j16000-j8000-8000}{800}
\]
注意：
\[
(800-j400)(20-j20)=16000-j16000-j8000+(-j400)(-j20)
\]
其中 \((-j400)(-j20)=j^2 8000=-8000\)，所以
\[
=16000-8000-j24000=8000-j24000
\]
于是
\[
Z_A=\frac{8000-j24000}{800}=10-j30\Omega
\]

从电源看进去：
\[
Z_{in}=R_1+Z_A=10+(10-j30)=20-j30\Omega
\]

#### 3. 电容电压有效值

总电流相量：
\[
\dot I=\frac{\dot U_S}{Z_{in}}=\frac{20\angle0^\circ}{20-j30}
\]
\[
20-j30=10(2-j3),\quad |20-j30|=\sqrt{20^2+30^2}=10\sqrt{13}
\]
所以
\[
\dot I=\frac{20}{20-j30}
=\frac{20(20+j30)}{20^2+30^2}
=\frac{400+j600}{1300}
=\frac{4+j6}{13}\text{ A}
\]

节点 A 电压：
\[
\dot U_A=\dot I Z_A
=\frac{4+j6}{13}(10-j30)
\]
先算：
\[
(4+j6)(10-j30)=40-j120+j60+180=220-j60
\]
所以
\[
\dot U_A=\frac{220-j60}{13}\text{ V}
\]
电容电压即 \(\dot U_A\)（因为电容接在 A 与地之间）。其有效值：
\[
U_C=|\dot U_A|=\frac{\sqrt{220^2+60^2}}{13}
=\frac{\sqrt{48400+3600}}{13}
=\frac{\sqrt{52000}}{13}
=\frac{20\sqrt{130}}{13}
\]
数值：
\[
U_C\approx \frac{20\times11.4017}{13}\approx17.54\text{ V}
\]

#### 4. 是否谐振

输入阻抗
\[
Z_{in}=20-j30\Omega
\]
虚部不为零，因此从电源端看**不发生谐振**。  
虽然串联电感与电容存在部分抵消，但总输入阻抗仍呈容性，故不是谐振状态。

> 隐性陷阱：\(L_1,L_2\) 串联且同名端同向时，等效电感为 \(L_1+L_2+2M\)，不是 \(L_1+L_2-2M\)。若误取减号，会得到不同结果并可能误判谐振。

### 答案

\[
\boxed{X_{L1}=10\Omega,\quad X_{L2}=20\Omega,\quad X_M=5\Omega}
\]
\[
\boxed{Z_{in}=20-j30\Omega}
\]
\[
\boxed{U_C=\frac{20\sqrt{130}}{13}\text{ V}\approx17.54\text{ V}}
\]
\[
\boxed{\text{电路未发生谐振，因为 }Z_{in}\text{ 虚部不为零。}}
\]

## 题目三（难题，跨模块 + 概念误导 + 定理前提甄别）

**范围：** 一阶暂态 + 二端口 + 均匀传输线/滤波器概念 + 定理前提甄别  
**难度：** 难

### 题目

如图所示电路，运算放大器为理想运放，工作于线性区。  
已知：
\[
R_1=1\text{ k}\Omega,\quad R_2=2\text{ k}\Omega,\quad C=1\mu F,
\]
输入电压 \(u_i(t)\) 为单位阶跃：
\[
u_i(t)=\varepsilon(t)\text{ V}
\]
运放输出端接一个二端口网络 N，其端口 2 接匹配负载 \(R_L=50\Omega\)。二端口 N 的 \(Z\) 参数为：
\[
Z_{11}=100\Omega,\quad Z_{12}=20\Omega,\quad Z_{21}=200\Omega,\quad Z_{22}=80\Omega
\]
（注意：\(Z_{12}\ne Z_{21}\)，网络含受控源，非互易。）

求：

1. 求运放输出端电压 \(u_o(t)\) 的表达式；
2. 求二端口网络 N 的输入端口电压 \(u_1(t)\) 的稳态值；
3. 判断能否用“互易定理”直接由 \(Z_{12}\) 与 \(Z_{21}\) 的关系说明该二端口网络满足互易性，并说明理由；
4. 若将二端口 N 视为一个滤波器，其端口 2 接 \(50\Omega\) 负载，问：仅根据给定 \(Z\) 参数能否判断其具有“低通/高通”滤波特性？说明概念前提。

```text
                 R2
          +----/\/\/\----+
          |              |
          |      |\      |
ui(t) --- R1 ----|-\     |
          |      |  >----+---- 端口1 ---- N ---- 端口2 ---- RL
          |      |/      |         (Z参数)
          |              |
         GND            GND
                C
                |
               GND
```

> 说明：运放反相输入端经 \(R_1\) 接 \(u_i\)，同时反相输入端经 \(C\) 接地；同相输入端经 \(R_2\) 接地（图中同相端通过 \(R_2\) 到地）。反馈电阻为 \(R_2\)，接在输出与反相输入端之间。  
> 即：反相端节点为 P；\(u_i\) 经 \(R_1\) 到 P；P 经 \(C\) 到地；P 经 \(R_2\) 到输出；同相端经 \(R_2\) 到地。  
> 注意图中同相端也画有 \(R_2\)，为避免混淆，以下按“反相端反馈电阻为 \(R_2=2k\Omega\)，同相端接地”的常见反相积分/低通结构计算。若同相端另接 \(R_2\)，因理想运放同相端无电流，同相端电位仍为 0，不影响传递函数。

### 解析

#### 1. 求 \(u_o(t)\)

对理想运放，反相端为虚地，节点 P 电位为 0。  
在节点 P 列 KCL（相量域或拉氏域）：

\[
