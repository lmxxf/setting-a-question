## 第 1 题（简单，30 分）——含受控源网络的戴维南等效与最大功率传输

**题干**：如图 1 所示电路，左侧独立电压源 $U_s = 36\ \text{V}$（上正下负，下端接参考地 $b$）串联电阻 $R_1 = 6\ \Omega$ 接至节点 $A$；节点 $A$ 与参考地 $b$ 之间接电阻 $R_2 = 12\ \Omega$，流过 $R_2$ 从 $A$ 向下的电流定义为控制量 $I_1$；节点 $A$ 向右串联电阻 $R_3 = 4\ \Omega$ 到达输出端口上端钮 $a$。在输出端钮 $a$ 与参考地端钮 $b$ 之间，并联一个方向由 $b$ 指向 $a$（向上注入节点 $a$）的受控电流源（CCCS，菱形符号），其电流大小为 $1\cdot I_1$；端口 $a$-$b$ 外接可变负载电阻 $R_L$（虚线连接）。

```text
R1 = 6 Ω         节点 A        R3 = 4 Ω                   a
    +------[ 6 Ω ]------------●-----------[ 4 Ω ]-----------●--------o - - - - +
    |                         |                             |                  |
    |                         | I1 (↓)                      |                  |
   (+)                        v                            / \                 |
  ( Us ) 36 V              [ R2 ] 12 Ω                    < ↑ > 1·I1 (CCCS)  [ RL ] (可变负载)
   (−)                        |                            \ /                 |
    |                         |                             |                  |
    +-------------------------●-----------------------------●--------o - - - - +
                              |                                      b
                             === (GND)
```

![题1图](q1.png)

**设问**：
1. 求端口 $a$-$b$ 以左电路的戴维南等效电压 $U_{oc}$ 与等效内阻 $R_{eq}$；
2. 求 $R_L$ 获得最大功率时的阻值 $R_{L,\text{opt}}$ 及该最大功率 $P_{\max}$。

**命题设计意图与陷阱剖析**：本题核心考点是**含受控源网络求戴维南等效内阻**。受控源不是独立源，**求等效电阻时绝不能将其置零开路**，必须用开路—短路法（$R_{eq}=U_{oc}/I_{sc}$）或外加电源法。若误将 CCCS 开路，会算出 $R_{eq}=(6\parallel12)+4=8\ \Omega$ 的错误结果，进而得到错误的 $P_{\max}$。此外，开路时受控源电流 $1\cdot I_1$ 全部经 $R_3$ 回流，使 $U_{oc}$ 高于 $U_A$，这是第二个易错点。

**标准分步解析**：

**(1) 求开路电压 $U_{oc}$**：端口 $a$-$b$ 断开时，受控电流源 $1\cdot I_1$ 的电流只能经 $R_3$ 向左流回节点 $A$。对节点 $A$ 列 KCL：
$$\frac{U_A-36}{6}+I_1-1\cdot I_1=0 \;\Rightarrow\; U_A=36\ \text{V}$$
故 $I_1=\dfrac{U_A}{12}=3\ \text{A}$。端口开路电压为
$$U_{oc}=U_a=U_A+R_3\cdot(1\cdot I_1)=36+4\times3=48\ \text{V}$$

**(2) 求短路电流 $I_{sc}$**：将 $a$-$b$ 短路（$U_a=0$），受控源电流直接流入短路支路。对节点 $A$ 列 KCL：
$$\frac{U_A-36}{6}+\frac{U_A}{12}+\frac{U_A}{4}=0 \;\Rightarrow\; U_A=12\ \text{V}$$
此时 $I_1=\dfrac{12}{12}=1\ \text{A}$，经 $R_3$ 流向 $a$ 的电流为 $\dfrac{12}{4}=3\ \text{A}$，故
$$I_{sc}=3+1\cdot I_1=3+1=4\ \text{A}$$

**(3) 戴维南等效内阻**：
$$R_{eq}=\frac{U_{oc}}{I_{sc}}=\frac{48}{4}=12\ \Omega$$

**(4) 最大功率传输**：当 $R_L=R_{eq}=12\ \Omega$ 时获最大功率
$$P_{\max}=\frac{U_{oc}^2}{4R_{eq}}=\frac{48^2}{4\times12}=48\ \text{W}$$

**答案**：$U_{oc}=48\ \text{V}$，$R_{eq}=12\ \Omega$，$R_{L,\text{opt}}=12\ \Omega$，$P_{\max}=48\ \text{W}$。

## 第 2 题（中等，30 分）——含受控源一阶电路的三要素法

**题干**：如图 2 所示电路，左侧独立直流电压源 $U_s = 30\ \text{V}$（上正下负，下端接参考地）串联电阻 $R_1 = 4\ \Omega$ 与开关 $S$（$t<0$ 时闭合已久达直流稳态，$t=0$ 时断开）接至节点 $A$；节点 $A$ 到参考地接电阻 $R_2 = 6\ \Omega$，流过 $R_2$ 向下的电流定义为控制量 $i_x$；节点 $A$ 向右依次串联电阻 $R_3 = 4\ \Omega$ 与受控电压源 VCVS（菱形符号，极性为左 $-$ 右 $+$，电压大小为 $2i_x$，控制系数 $r=2\ \Omega$）到达节点 $B$；节点 $B$ 到参考地接电容 $C = 0.25\ \text{F}$（电容电压 $u_C(t)$ 上正下负，电容电流 $i_C(t)$ 参考方向向下）。

```text
R1 = 4 Ω     S (t=0 断开)   节点 A      R3 = 4 Ω        2ix (VCVS)     节点 B
    +------[ 4 Ω ]------o  /  o---------●---------[ 4 Ω ]--------< −   + >---------●-------+
    |                                   |                                                  |
    |                                   | ix (↓)                                           | iC(t) (↓)
   (+)                                  v                                               +  v
  ( Us ) 30 V                         [ R2 ] 6 Ω                                   uC(t) ===== C = 0.25 F
   (−)                                  |                                               -  |
    |                                   |                                                  |
    +-----------------------------------●--------------------------------------------------+
                                        |
                                       === (GND)
```

![题2图](q2.png)

**设问**：
1. 求换路前稳态值 $i_x(0_-)$、$u_A(0_-)$ 及电容初始电压 $u_C(0_+)$；
2. 求 $t\ge0$ 时电容端口看进去的戴维南等效电阻 $R_{eq}$ 与时间常数 $\tau$；
3. 用三要素法写出 $u_C(t)$、$i_C(t)$（$t\ge0$），并求 $i_x(0_+)$，说明电阻电流是否跃变。

**命题设计意图与陷阱剖析**：本题设两个隐性陷阱。**陷阱一**：$t=0_-$ 时电容开路、支路电流为零，但串联在支路上的受控电压源 $2i_x$ 两端仍有 $6\ \text{V}$ 电压，由 KVL 得 $u_C(0_-)=u_A+2i_x=24\ \text{V}$；若误认为"支路无电流即无压降"会错得 $18\ \text{V}$。**陷阱二**：求时间常数时受控源必须保留，用外加电源法得 $R_{eq}=R_3+2+R_2=12\ \Omega$；若将受控源置零短路会错得 $10\ \Omega$。此外，换路后电阻电流 $i_x$ 由 $3\ \text{A}$ 跃变为 $2\ \text{A}$，体现电容电压连续而电阻电流可跃变。

**标准分步解析**：

**(1) 换路前稳态（$t=0_-$）**：$S$ 闭合，电容开路，$i_C(0_-)=0$。左侧回路电流
$$i_x(0_-)=\frac{U_s}{R_1+R_2}=\frac{30}{4+6}=3\ \text{A},\qquad u_A(0_-)=R_2\,i_x(0_-)=6\times3=18\ \text{V}$$
电容支路虽无电流，但受控源电压为 $2i_x(0_-)=6\ \text{V}$，由 KVL：
$$u_C(0_-)=u_A(0_-)+2i_x(0_-)=18+6=24\ \text{V}$$
由换路定则 $u_C(0_+)=u_C(0_-)=24\ \text{V}$。

**(2) 换路后等效电阻与时间常数**：$t\ge0$ 时 $S$ 断开，左支路脱离，电路为零输入响应（$u_C(\infty)=0$）。在电容端口外加电压 $u$，设从节点 $B$ 向左流入 $R_3$ 的电流为 $i$，该电流全部经节点 $A$ 流过 $R_2$ 下地，故 $i_x=i$。由 KVL：
$$u=R_3 i+2i_x+R_2 i_x=(4+2+6)i=12i \;\Rightarrow\; R_{eq}=12\ \Omega$$
$$\tau=R_{eq}C=12\times0.25=3\ \text{s}$$

**(3) 三要素法**：$u_C(0_+)=24\ \text{V}$，$u_C(\infty)=0$，$\tau=3\ \text{s}$，故
$$u_C(t)=24\,e^{-t/3}\ \text{V}\quad(t\ge0)$$
$$i_C(t)=C\frac{du_C}{dt}=0.25\times\left(-8e^{-t/3}\right)=-2e^{-t/3}\ \text{A}\quad(t\ge0)$$
即 $i_C(0_+)=-2\ \text{A}$。由 KCL，$i_x(t)=-i_C(t)=2e^{-t/3}\ \text{A}$，故 $i_x(0_+)=2\ \text{A}$。对比 $i_x(0_-)=3\ \text{A}$，**电阻电流在换路瞬间发生跃变**（电容电压则连续）。

**答案**：$i_x(0_-)=3\ \text{A}$，$u_A(0_-)=18\ \text{V}$，$u_C(0_+)=24\ \text{V}$；$R_{eq}=12\ \Omega$，$\tau=3\ \text{s}$；$u_C(t)=24e^{-t/3}\ \text{V}$，$i_C(t)=-2e^{-t/3}\ \text{A}$，$i_x(0_+)=2\ \text{A}$（发生跃变）。

## 第 3 题（困难，40 分）——含受控源二端口的 Z 参数、互易性甄别与功率叠加

**题干**：如图 3 所示，虚线框内为含受控源的线性二端口网络 $N$（左端口 $1$-$1'$，右端口 $2$-$2'$，$1'$-$2'$ 为底部直通公共参考端，标准参考方向：$I_1$ 从端钮 $1$ 流入，$I_2$ 从端钮 $2$ 流入）。内部为 T 型网络：端钮 $1$ 串联 $R_1=2\ \Omega$ 到内部节点 $M$；节点 $M$ 到公共底线接 $R_2=4\ \Omega$；节点 $M$ 向右串联 $R_3=2\ \Omega$ 与受控电压源 VCVS（菱形符号，极性左 $-$ 右 $+$，电压为 $4I_1$）到达端钮 $2$。外部电路：端口 $1$-$1'$ 外接独立电压源 $U_{s1}=32\ \text{V}$（上正下负）串联内阻 $R_s=2\ \Omega$；端口 $2$-$2'$ 外接独立电流源 $I_{s2}=8\ \text{A}$（方向由 $2'$ 向上指向 $2$）与负载电阻 $R_L=6\ \Omega$ 并联（设流过 $R_L$ 向下的负载电流为 $I_L$，负载电压 $U_L=U_2$ 上正下负）。

```text
+ - - - - [ 含受控源线性二端口网络 N ] - - - - +
         Rs = 2 Ω   I1  |    R1 = 2 Ω       节点 M   R3 = 2 Ω   4I1    |   I2
    +----[ 2 Ω ]--->--o 1 ---[ 2 Ω ]---------●------[ 2 Ω ]---< − + >--o 2 --<--+----------+
    |                   |                    |                         |        |          |
   (+)                  |                    |                         |       (↑)         | IL (↓)
  (Us1) 32 V            |                 [ R2 ] 4 Ω                   |      (Is2) 8 A  [ RL ] 6 Ω
   (−)                  |                    |                         |       ( )         |
    |                   |                    |                         |        |          |
    +-----------------o 1'-------------------●-------------------------o 2'-----+----------+
                        + - - - - - - - - - - - - - - - - - - - - - - -+
```

![题3图](q3.png)

**设问**：
1. 求二端口 $N$ 的 $Z$ 参数矩阵，并据此判断该网络是否满足互易定理，说明原因；
2. 求双电源共同作用下的 $I_1$、$I_2$、$I_L$、$U_L$ 及负载吸收功率 $P_L$；
3. 用叠加定理分别求 $U_{s1}$ 单独作用与 $I_{s2}$ 单独作用时的 $I_L'$、$P_L'$ 与 $I_L''$、$P_L''$，验证电流叠加成立而功率不可叠加，并求功率差值 $\Delta P$。

**命题设计意图与陷阱剖析**：本题跨"二端口 + 电路定理"两大模块。**概念误导**：网络内部含受控源 $4I_1$，破坏互易性，$Z_{12}\neq Z_{21}$；若误按互易定理令 $Z_{21}=Z_{12}=4\ \Omega$，联立外电路会算出错误负载电压 $U_L=144/5=28.8\ \text{V}$。**定理前提甄别**：叠加定理仅对线性响应（电流、电压）成立，功率是电流的二次函数，**不能直接叠加**；差值恰为交叉耦合项 $2I_L'I_L''R_L$。**符号陷阱**：受控源 $4I_1$ 左 $-$ 右 $+$ 使端钮 $2$ 电位高于节点 $M$，故 $U_2=R_2(I_1+I_2)+4I_1+R_3I_2=8I_1+6I_2$，切勿漏加或反号。

**标准分步解析**：

**(1) 求 $Z$ 参数并甄别互易性**：对内部 T 型网络列 KVL。受控源 $4I_1$ 左 $-$ 右 $+$，使端钮 $2$ 电位比节点 $M$ 进一步升高 $4I_1$：
$$U_1=R_1I_1+R_2(I_1+I_2)=6I_1+4I_2$$
$$U_2=R_2(I_1+I_2)+4I_1+R_3I_2=8I_1+6I_2$$
故
$$\boldsymbol{Z}=\begin{bmatrix}6&4\\8&6\end{bmatrix}\Omega,\quad Z_{11}=6,\ Z_{12}=4,\ Z_{21}=8,\ Z_{22}=6\ (\Omega)$$
因 $Z_{12}=4\ \Omega\neq Z_{21}=8\ \Omega$，**该二端口不满足互易定理**——内部含受控源 $4I_1$，受控源是单向传输元件，破坏了网络的互易性。

**(2) 双电源共同作用**：端口 $1$ 外电路 $U_1=32-2I_1$，代入 $U_1=6I_1+4I_2$：
$$8I_1+4I_2=32 \tag{①}$$
端口 $2$ 节点 KCL：$I_{s2}=I_2+I_L\Rightarrow I_L=8-I_2$，故 $U_2=U_L=6(8-I_2)=48-6I_2$，代入 $U_2=8I_1+6I_2$：
$$8I_1+12I_2=48 \tag{②}$$
联立①②解得 $I_1=3\ \text{A}$，$I_2=2\ \text{A}$。于是
$$I_L=8-2=6\ \text{A},\quad U_L=6\times6=36\ \text{V},\quad P_L=I_L^2R_L=6^2\times6=216\ \text{W}$$

**(3) 叠加定理分量与功率差值**：

*(a) 仅 $U_{s1}=32\ \text{V}$ 作用*（$I_{s2}=0$ 开路，受控源保留）：联立 $8I_1'+4I_2'=32$ 与 $8I_1'+12I_2'=0$，解得 $I_1'=6\ \text{A}$，$I_2'=-4\ \text{A}$。故
$$I_L'=-I_2'=4\ \text{A},\quad U_L'=24\ \text{V},\quad P_L'=(4)^2\times6=96\ \text{W}$$

*(b) 仅 $I_{s2}=8\ \text{A}$ 作用*（$U_{s1}=0$ 短路，受控源保留）：联立 $8I_1''+4I_2''=0$ 与 $8I_1''+12I_2''=48$，解得 $I_1''=-3\ \text{A}$，$I_2''=6\ \text{A}$。故
$$I_L''=8-6=2\ \text{A},\quad U_L''=12\ \text{V},\quad P_L''=(2)^2\times6=24\ \text{W}$$

*(c) 对比验证*：电流满足线性叠加
$$I_L=I_L'+I_L''=4+2=6\ \text{A}\ \checkmark$$
但功率直接相加
$$P_L'+P_L''=96+24=120\ \text{W}\neq P_L=216\ \text{W}$$
差值
$$\Delta P=P_L-(P_L'+P_L'')=216-120=96\ \text{W}$$
恰等于二次型展开中的交叉耦合功率项 $2I_L'I_L''R_L=2\times4\times2\times6=96\ \text{W}$。这定量印证了**叠加定理只适用于线性响应，功率不可叠加**。

**答案**：$\boldsymbol{Z}=\begin{bmatrix}6&4\\8&6\end{bmatrix}\Omega$，$Z_{12}\neq Z_{21}$，**非互易**；$I_1=3\ \text{A}$，$I_2=2\ \text{A}$，$I_L=6\ \text{A}$，$U_L=36\ \text{V}$，$P_L=216\ \text{W}$；$I_L'=4\ \text{A}$、$P_L'=96\ \text{W}$，$I_L''=2\ \text{A}$、$P_L''=24\ \text{W}$，$\Delta P=96\ \text{W}$（等于交叉耦合项 $2I_L'I_L''R_L$）。

**卷末提示**：第 1 题重在"受控源不可置零"的等效内阻求法；第 2 题重在"开路支路受控源压降"与"时间常数中受控源保留"两个隐性陷阱；第 3 题重在"含受控源破坏互易性"的甄别与"功率不可叠加"的定量验证。三题层层递进，望对照解析复盘每一步 KCL/KVL 的符号与前提。
